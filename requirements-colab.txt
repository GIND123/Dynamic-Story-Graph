# IMPORTANT - torch is deliberately NOT pinned in this file.
#   Colab ships a torch build already matched to its CUDA driver. Reinstalling
#   torch on Colab is slow and frequently breaks the runtime, so the bootstrap
#   (`python -m gnsm.colab.bootstrap`) installs torch ONLY if it is missing,
#   using the official cu121 wheel index:
#
#       pip install torch --index-url https://download.pytorch.org/whl/cu121
#
#   Everything below layers cleanly on top of Colab's preinstalled torch.
#   For a non-Colab GPU machine with no torch, run the bootstrap first (it
#   installs torch), then `pip install -r requirements-colab.txt`.
